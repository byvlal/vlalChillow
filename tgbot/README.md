# Telegram-бот влалChillow

Отдельный процесс, который повторяет сайт без админки: кнопочный бот на русском.
Обслуживает один сервер — Новосибирск (`skam.su/vlalchillow`). Локального стенда
в боте нет: панель, ключ и адрес для игроков задаются один раз в `.env`.

```
tgbot/
├── StandChillow.Bot.Contracts/   клиент панели и DTO (без Telegram)
├── StandChillow.Bot/             сам бот: экраны, SQLite, polling
├── deploy/                       systemd-юнит и установка
├── .env.example
└── README.md
```

## Что умеет

- вход по коду из лобби (6 цифр), привязка запоминается в SQLite;
- статус, комнаты и карточка комнаты;
- создание комнаты (режим → карта → размер команды → название);
- завершение своей комнаты;
- профиль и статистика;
- история матчей и полная таблица катки;
- поиск игрока по ID, кастомному ID или нику;
- жалобы и «мои жалобы»;
- список администрации;
- инструкция с адресом сервера.

Админка сайта боту закрыта на сервере: `/api/bot/api/admin/*` отвечает
`403 bot_admin_forbidden`.

## Серверная часть

В сервер уже встроен ботовский вход:

- ключ лежит в `auth/tgbot/password.txt` (64 hex, каталог 700, файл 600);
- создаётся при первом старте сервера;
- `GET /api/bot` — рукопожатие;
- все данные — под `/api/bot/*` с заголовком `X-Bot-Key`;
- сброс: команда `tgbot resetkey` в консоли сервера. Старый ключ умирает сразу,
  новый печатается только в `/dev/tty` (в `latest.log` попадает лишь путь).

Пока на сервере старый билд без `/api/bot`, бот будет получать 404/403. Сначала
обнови серверный билд, потом запускай бота.

## Настройка бота

```bash
cp tgbot/.env.example tgbot/.env
chmod 600 tgbot/.env
```

Заполни:

| Переменная | Что это |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от [@BotFather](https://t.me/BotFather) |
| `SITE_URL` | сайт с панелью, по умолчанию `https://skam.su/vlalchillow` |
| `BOT_KEY` | ключ из `auth/tgbot/password.txt` |
| `GAME_ADDRESS` | адрес для игроков, по умолчанию `212.164.115.37:7778` |
| `BOT_LABEL` | подпись сервера, по умолчанию `Новосибирск` |
| `TELEGRAM_PROXY` | прокси только для Telegram; панель ходит напрямую |
| `BOT_DB_PATH` | база привязок, по умолчанию `data/bot.db` |
| `BOT_TIMEZONE` | часовой пояс для дат, по умолчанию `Asia/Novosibirsk` |

`SITE_URL` можно указывать с `/api/bot` на конце или без — бот не удвоит путь.
`GAME_ADDRESS` принимается и как `212.164.115.37:7778`, и как
`https://212.164.115.37:7778/`.

## Один сервер

Бот ходит только на Новосибирск. Код из лобби проверяется там же, успешный вход
заменяет прежнюю привязку. Если сервер недоступен, бот так и пишет — локального
запасного пути нет.

В базе одна строка на Telegram ID. Старая таблица с `server_id` мигрирует при
старте: остаётся самая свежая привязка человека, остальные строки удаляются.

## Сборка и запуск

На сервере нужен .NET 8 runtime (SDK — только для сборки).

```bash
# из корня репозитория
tgbot/deploy/publish.sh

# на сервере, от root
tgbot/deploy/install.sh /путь/к/tgbot/publish
```

`install.sh` кладёт файлы в `/opt/vlalchillow-tgbot`, создаёт `data/` с правами
700, ставит `vlalchillow-tgbot.service` и запускает его. `.env` не перезаписывает.

Проверка:

```bash
systemctl status vlalchillow-tgbot
journalctl -u vlalchillow-tgbot -f
```

В логе при старте видно сервер и рукопожатие:

```
[bot] сервер (Новосибирск): панель https://skam.su/vlalchillow/api/bot, игра 212.164.115.37:7778
[bot] панель ответила: vlalchillow, api 1
```

## Как пользоваться

1. Открой бота, пришли `/start`.
2. Зайди в игру, возьми код из 6 цифр в лобби, пришли боту.
3. Дальше — кнопки: «Статус», «Комнаты», «Создать», «Профиль», «Матчи»,
   «Игрок», «Мои жалобы», «Админы», «Инструкция».

Новый код из лобби заменяет привязку — выходить для этого не нужно.

Сессия живёт 30 дней и переживает перезапуск бота. Когда сервер её больше не
принимает (401), бот сам удалит привязку и попросит новый код.

## Группы

В личке бот отвечает на любое текстовое сообщение. В группе — только если к нему
обратились:

- команда (`/start`, `/menu`, `/help`, `/logout`, `/cancel`);
- упоминание `@vlalikoffcChillowbot` в тексте;
- ответ на сообщение бота.

Обычные реплики в группе бот игнорирует. Сообщения из каналов и от других ботов
тоже. Сообщения старше 60 секунд не обрабатываются — это защищает от пачки
старых апдейтов после перезапуска или долгой очереди.

Каждый человек в группе входит под своим Telegram ID: привязка, визарды и
сессия у всех свои. Код из лобби в группе видят все, поэтому бот предупреждает:
лучше присылать его в личку.

Исходящие вызовы ограничены с запасом от лимитов Telegram: 1 сообщение в секунду
в один чат, 20 в минуту в группу, 25 в секунду на всего бота. Правка сообщения
считается так же, как отправка.

## Безопасность

- `.env` и база не попадают в git (`.gitignore`);
- ключ бота не пишется в логи и не отдаётся сайту;
- бот не хранит паролей: только код из лобби, обменянный на сессию;
- панель вызывается напрямую, `UseProxy = false`; прокси — только для Telegram;
- админские маршруты под ботом закрыты.

## Если не работает

| Симптом | Что проверить |
|---|---|
| `bad_bot_key` | ключ в `.env` не совпадает с `auth/tgbot/password.txt`; сбрось `tgbot resetkey` |
| `bot_disabled` | на сервере старый билд без ботовского входа |
| `bot_key_unavailable` | сервер не смог создать файл ключа: права на `auth/tgbot` |
| «Не смог проверить код: … не отвечает» | Новосибирск недоступен; проверь адрес и сеть |
| `player_offline` | игрок вышел из лобби — зайди снова |
| «Сессия истекла» | пришли новый код из лобби |
| Telegram не отвечает | проверь `TELEGRAM_PROXY`; панель при этом может быть жива |

## Тесты

Контрактные тесты поднимают настоящий `WebPanelRouter` в процессе и гоняют через
`PanelClient` с поддельным `HttpMessageHandler`. Переименование поля в JSON ломает
тест, а не бота в бою.

Тесты бота проверяют разбор `.env` (один сервер, адрес панели, ключ), SQLite-привязки
(одна на человека, миграция старой таблицы), фильтр групп и старых сообщений, а
также лимиты отправки.

```bash
dotnet test tests/StandChillow.Bot.Contracts.Tests/StandChillow.Bot.Contracts.Tests.csproj
dotnet test tests/StandChillow.Bot.Tests/StandChillow.Bot.Tests.csproj
```
