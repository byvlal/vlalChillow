# План доработки сайта влалChillow

Статус: этап 1 «обложки + создание комнаты» готов. Этап 2 «визуальное наполнение»
реализован по этому плану, ждёт оценки влала.

База не переделывается: палитра, шрифты, hero, карточки, сетки, админка и
десктопная шапка остаются. Добавляем картинки и шапки в том же стиле.

- [x] `/api/modes`: `image` для режима и `levelImages` (карта → URL).

## 2. Вкладка создания комнаты — готово

- ПК: слева создание (режимы-постеры, карты-плитки, итог), справа список комнат

## 3. Этап 2 — визуальное наполнение

Цель: убрать ощущение «просто шрифт на тёмном фоне». Новые картинки — только
прямые ссылки с Standoff 2 Wiki. Точные URL и размеры — `docs/SITE_ART_SOURCES.md`.

### 3.1. P1 — комнаты и матч

`#/room/<n>` и `#/match/<id>` сейчас: заголовок, мета-строка, таблица. Карты не видно.

Делаем баннер внутри `.so-ms`:

- фон — обложка карты из `MODES.levelImages` (640×360), `object-fit: cover`;
- тёмный градиент слева и снизу, чтобы текст читался;
- комната: сверху `КОМНАТА #n` + бейдж состояния; снизу имя комнаты, режим · карта;
  справа крупный счёт `CT : T` (если матч идёт/закончен) или места;
- матч: сверху `МАТЧ #id` + бейдж победителя; снизу режим · карта и дата;
  справа финальный счёт;
- мета-строка ниже остаётся, но без дублей «режим · карта» и счёта;
- нет картинки — тот же баннер на градиенте по хэшу карты, без дыр в вёрстке.

Высота: 200px на ПК, 150px на телефоне. Только `index.html`, сервер не трогаем.

### 3.2. P1 — главная, «Прямо сейчас»

Под четырьмя цифрами добавляем «ОТКРЫТЫЕ КОМНАТЫ» и до трёх живых карточек:

- миниатюра карты 16:9, имя комнаты, режим · карта, места/счёт, бейдж состояния;
- ссылка на `#/room/<n>`, справа «ВСЕ КОМНАТЫ →»;
- данные — уже существующий глобальный `rooms`, обновление каждые 2 с, новый API не нужен;
- комнат нет — богатый пустой блок с картой/логотипом и кнопкой «СОЗДАТЬ КОМНАТУ»;
- на телефоне — одна колонка или горизонтальный скролл с прилипанием.

### 3.3. P2 — администрация, репорты, админ-консоль

Верх этих страниц — заголовок и абзац на тёмном фоне. Делаем общую шапку
`.so-pagehero`: фон главного меню Standoff 2 — фон на всю площадь, поверх него
слева кикер, заголовок, подпись и бейдж. Фото не отдельная панель и не полоса
сверху: на телефоне оно остаётся фоном под текстом.

Картинки:

- `#/administration` — Osiris (1.0.0), золото/пустыня, «АДМИНИСТРАЦИЯ СЕРВЕРА»;
- `#/reports` — Paranoia (1.1.0), красно-синий, «ЖАЛОБЫ ИГРОКОВ»;
- `#/admin` — Year of Horse (0.37.1), красный пиджак, «АДМИН-КОНСОЛЬ».

Формы, таблицы и карточки не трогаем. Счётчик админов появляется после загрузки
списка, если данные уже есть.

### 3.4. P2 — пустые состояния

Сейчас `.so-repempty` — серая плашка с текстом, 15+ мест. Переводим на богатый
`.so-empty--rich`:

- значок `◆`, короткий заголовок, одна строка пояснения, кнопка действия;
- на фоне — логотип Standoff 2 с прозрачностью 6–8% (водяной знак, не мешает тексту);
- места: история профиля и игрока, админ-журнал, комнаты, баны, сессии, неудачные
  входы, жалобы, конфиг, поиск игроков, администрация, список комнат;
- «Загружаю…» оставляем простым текстом, богатый блок — только для реально пустых.

### 3.5. P3 — play, profile, player

- `#/play` — шапка `.so-pagehero` с фоном меню 0.38.1, заголовок «ИГРАТЬ СЕЙЧАС»,
  подпись и живые пилюли онлайн/комнаты внутри шапки. Сетка создания и список ниже
  без изменений.
- `#/profile` — шапка с фоном меню 0.36.0 (Día de Muertos), аватар 88px,
  ник и ID; аноним видит ту же шапку и форму входа ниже, рядом с памяткой

- `#/player/<id>` — шапка с фоном меню 0.34.0 (Beholder Gambit), аватар, ник, ID,
  кнопка «ПОЖАЛОВАТЬСЯ». Карточки статистики и история ниже без изменений.

### 3.6. P3 — главная, «О проекте» и «Как начать»

- `#sec-about`: под фактами — мозаика из 4 карт (Prison, Sandstone, Hanami, Rust)
  с подписями и ссылкой «ВСЕ КАРТЫ → #/play». На ПК 4 в ряд, на телефоне 2×2.
- `#sec-how`: над шагами — полоса из трёх существующих скриншотов
  `media/doc-1.jpg`, `media/doc-3.jpg`, `media/doc-6.jpg` с подписями
  «LAN», «АДРЕС», «КОД». Восемь шагов остаются как есть.

### 3.7. P3 — фон страниц

Вместо плоской заливки `#0b141c` — фиксированный слой `.so-pagebg` внутри
каждого экрана, за карточками и текстом. У каждого экрана свой фон главного
меню Standoff 2 (не загрузочный экран):

- `#/` — 0.35.0, самурай;
- `#/docs` — 0.29.0, сине-бирюзовый знак;
- `#/play` — 0.38.1, «9 лет»;
- `#/profile` — 0.36.0, череп с розами;
- `#/player/<id>` — 0.34.0, ромб-глаз;
- `#/admin` — 0.37.1, конь;
- `#/reports` — 1.1.0, красно-синий демон;
- `#/administration` — 1.0.0, фараон;
- `#/room/<n>` и `#/match/<id>` — арт текущей карты через `mapArtFor()`.

Слой `position:fixed; inset:0; z-index:-1`, экран создаёт stacking context.
Сверху — градиент и виньетка; тёмные фоны видны на 55–65%, 0.29.0 затемнён
сильнее. Шапки страниц используют те же фоны меню.

### 3.8. P4 — рейтинг, живой онлайн, переходы

**Таблица лидеров `#/top`.** Отдельный экран с фоном меню 0.39.0: шапка, вкладки
сортировки (киллы / K/D / время / матчи) и строки — место, ник, ID, четыре цифры.
Источник — тот же `PlayerStatsStore`, что и профиль: `GET /api/top?sort=…&limit=…`.
Баненые и записи без киллов и матчей в зачёт не идут. Пусто — богатое пустое
состояние, а не серая плашка.

**Живой онлайн списком.** В `/api/status` добавлен массив `players`: id, ник,
комната (0 — лобби), команда, админ-флаг и отображаемый ID. Собирается из лобби и
живых составов комнат, дубли по id схлопываются — игрок в катке не висит дважды.
На главной под цифрами «Прямо сейчас» — плитки «кто в сети», каждая ведёт на
профиль. Отдельного запроса и таймера нет: данные приходят со статусом.

**Переходы.** При смене экрана новый view проявляется за 220 мс, контент
поднимается на 12 px за 260 мс. Класс `is-enter` ставится только когда экран
реально сменился, поэтому переходы внутри одной страницы анимацию не играют.
`prefers-reduced-motion` выключает всё.

### 3.9. Что не делаем

- `#/docs` не переделываем: только фон 0.29.0, текст и шаги остаются.
- UDP/протокол и серверные API не меняем.
- Недельный/месячный рейтинг: статистика хранит только суммы за всё время.

## 4. Общие компоненты

- `.so-pagehero` — шапка страницы с фоном меню на фоне и текстом поверх.
- `.so-pagebg` — фиксированный фон страницы за контентом.
- `.so-card--split` — карточка в две колонки: форма + боковая памятка.
- `.so-rpmain` — рабочая колонка жалоб + липкая памятка сбоку.
- `.so-ms__art` — баннер карты в комнате/матче.
- `.so-hrooms` — мини-лента комнат на главной.
- `.so-mapwall` — мозаика карт в «О проекте».
- `.so-empty--art` — пустое состояние с водяным знаком.
- JS: `mapArtFor(modeId, level)`, `renderHomeRooms()`, `emptyRich(...)`.

## 5. Порядок и риски

1. CSS-компоненты и хелперы.
2. P1: комната/матч + лента на главной.
3. P2: шапки администрации/репортов/консоли + пустые состояния.
4. P3: play/profile/player + «О проекте»/«Как начать».
5. Сборка `Release`, перезапуск, проверка по коду; при необходимости один
   контрольный скриншот.

Риски:

- Fandom может не открыться (VPN) — у всех картинок градиент/скрытие, вёрстка не ломается.
- На фонах меню есть центральные эмблемы — кадрируем шапку и закрываем
  градиентом, чтобы они не спорили с нашим заголовком.
- На телефоне шапки не должны перекрывать контент — фиксированная высота арта,
  текст отдельным блоком.
- Вес: 8 фонов по 14–57 КБ в 1280; шапки используют те же URL и кэшируются.
