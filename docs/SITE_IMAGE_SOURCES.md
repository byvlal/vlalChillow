# Источники обложек режимов и карт

Обложки не хранятся в репозитории: страница загружает их по прямым ссылкам
с CDN Fandom (`static.wikia.nocookie.net`). Панель отправляет
`Referrer-Policy: no-referrer`, поэтому вики не видит сайт как источник запроса.
Если картинка не загрузилась, карточка остаётся с градиентом по хэшу имени.

Источники каталога:

- [Категория:Карты](https://standoff-2.fandom.com/ru/wiki/Категория:Карты)
- [Категория:Режимы](https://standoff-2.fandom.com/ru/wiki/Категория:Режимы)

Проверено: все ссылки ниже отвечают `200` без Referer. Карты — 640×360;
обложки режимов разного формата, поэтому карточки режимов — 3:4 с `object-fit: cover`.
