# Дизайн-система сайта vlalChillow

Сайт выглядит как продолжение интерфейса StandChillow: та же типографика, те же цвета,
те же полупрозрачные панели. Никаких неоновых градиентов, фиолетовых «нейро»-палитр
и свечения ради свечения.

## Основа

| Слой | Решение |
|---|---|
| Дисплейный шрифт | **Bebasbolt** (все заголовки, кнопки, цифры — капсом) |
| Текстовый шрифт | **Roboto** 400/500/700 — тот самый шрифт игры на Android |
| Отдача шрифтов | `/media/*.woff2`, вкомпилированы в exe, кэш год |
| Палитра | тёмно-синий интерфейс игры, акценты CT/T |
| Эффект «вау» | видео-герой с реальным геймлеем сервера |

Лицензии: Bebasbolt — CC-BY-4.0 (Wanja01 & Snowy) — кредит в подвале обязателен.
Roboto — Apache 2.0.

## Токены (`--so-*`)

```
--so-bg     #0b141c   фон страницы (совпадает с dark surface игровой страницы)
--so-bg-2   #0e1d29   заливка ячеек статуса
--so-panel  rgba(12,27,39,.55)  полупрозрачные панели (backdrop-blur)
--so-line   rgba(154,196,226,.14)   волосяные линии (1px)
--so-line-strong  rgba(154,196,226,.32)  рамки кнопок-призраков
--so-text   #e9f0f6   основной текст
--so-muted  #90a7b8   вторичный текст
--so-ct     #8fb4e8   синие CT  ← акцент по умолчанию
--so-t      #e8a33d   оранжевые T
--so-hp     #f0c33c   HP-жёлтый
--so-acc    акцент текущей темы (CT / T / HP), --so-acc-ink — текст на нём
```

Правило цвета: акцент один на экран. Он красит «СЕРВЕР» в заголовке, ключевые
цифры, ссылки-стрелки и логотип. Всё остальное — белый, muted и линии.

## Типографика

- Заголовки H1 — `clamp(62px, 10.5vw, 148px)`, line-height `.9`, только капс.
- Секционные H2 — `clamp(42px, 6vw, 76px)`.
- Цифры статуса — 58px Bebasbolt.
- Обычный текст 14–16px Roboto, line-height 1.5–1.65.
- Интерлиньяж дисплейного: `letter-spacing: .08–.14em` у мелкого капса,
  у гигантских заголовков — почти ноль (`.008em`).

## Компоненты

- **Кнопка ИГРАТЬ** (`.so-btn--play`): светло-голубая плашка с вертикальным
  градиентом `#b6cbe7→#9db6d7`, тёмный текст `#0c1721`, радиус 6px, внутренний
  блик сверху. Вторая кнопка — тёмное стекло с рамкой (`.so-btn--ghost`).
- **Ссылка-стрелка** (`.so-howlink`): акцентный капс + стрелка, стрелка уезжает
  на 5px при ховере.
- **Секции**: label-строка «О ПРОЕКТЕ ─────» (капс + линия), затем H2.
- **Факты** (`.so-facts__row`): `КЛЮЧ | описание | значение` в одну строку
  с волосяными линиями; значение — акцентным капсом.
- **Шаги** (`.so-step`): контурные цифры 01–03 (-webkit-text-stroke), текст,
  справа опциональная ссылка.
- **Статус** (`.so-now`): 4 ячейки в 1px-сетке, как табло.
- **Бегущая строка** (`.so-marquee`): режимы сервера из каталога, diamonds ◆
  оранжевые, дублируется дважды для бесшовного цикла.
- **Подвал**: links Telegram/GITHUB капсом с иконками, кредит шрифта.
- **Drawer-панель** (кнопка «ПАНЕЛЬ» в навбаре каждой страницы): затемнение
  `.so-scrim` + правая шторка `.so-side`; блок аккаунта `.so-side__acc` (аватар
  `.so-avatar`, ник/ID) или форма входа `.so-side__anon` (`.so-input` + `.so-btn`),
  меню `.so-sidebtn` (Профиль / Играть / Репорты / Админ панель — пункт виден
  только админам, ведёт на `#/admin`), внизу «Выйти». Закрытие: крестик, клик по
  scrim, Escape.
- **Экран входа `#/play` (гейт, `.so-gate`)**: пока нет сессии — вместо интерфейса
  карточка «СНАЧАЛА ВХОД»: надпись-кикер, три мини-шага (`.so-gate__step`:
  номер бейсболтом, заголовок, подпись), CTA «ПЕРЕЙТИ К ВХОДУ» (`.so-btn--play`
  → `#/profile`) и ghost «Где взять код?» — глубокая ссылка на шаг 06 инструкции.
  Формы кода внутри комнат больше нет: вход живёт в профиле и drawer.
- **Сетка комнат (`.so-playgrid`)**: на десктопе две панели — создание слева
  (фикс ~430px), список справа; на телефоне панели стопкой, переключает
  мини-таб `.so-tabs--mini` (`data-tab` на сетке).
- **Панель создания (`.so-create`)**: кикер «◆ ЛОББИ», заголовок «НОВАЯ КОМНАТА»,
  шаги без нумерации. Режимы — карточки `.so-mode` (имя бейсболтом, счёт карт,
  водяной знак алиаса TDM/FFA, выбранный — акцентная рамка + ◆); размер команды —
  чипы `.so-chip`; карты — плитки `.so-map` 16:9 с градиентом из хэша имени
  (`huePair`), имя внизу, выбранная — акцентная рамка + ◆-маркер. Ниже — живая
  строка `.so-create__sum` («Командный бой ◆ 2 на 2 ◆ Perimeter ◆ имя»),
  обновляется на каждом выборе (`updateCreatePreview()`), и большая кнопка
  «СОЗДАТЬ КОМНАТУ» (`.so-btn--play`).
- **Нумерованные шаги «что дальше»** (`.so-steps li`): квадратики 01/02/03
  (бейсболт, акцент) слева, текст справа; используются и в результате создания
  (`.so-result`: «Комната открыта — осталось войти» + команда `.so-cmd` + копия),
  и в окне входа (`.so-dlg`, модалка со scrim).
- **Карточки комнат (`.so-room`)**: слева градиентный блок режима
  (`.so-room__mode`, цвет из хэша алиаса, водяной знак + `#номер`), тело —
  название + бейджи (`.so-badge`: моя/идёт/ожидание/конец/заполнена) и мета
  (режим · размер · карта · хост), справа — счёт CT:T (CT синим, T оранжевым,
  в ожидании «—»), чип мест `0 / 16` (краснеет при полном), акцентная кнопка
  «ВОЙТИ» (`.so-btn--acc`) и «Завершить» у своей комнаты. Пустой список —
  богатый empty-стейт с ◆ и кнопкой «СОЗДАТЬ КОМНАТУ» (перекидывает на создание).
- **Профиль** (`#/profile`): K/D-пончик (SVG, кольца убийств синим, смертей
  оранжевым, центр — KD), тайлы-факты (убийства/смерти/время в матчах/
  уникальные матчи), карточка ника с аватаром.
- **Админ панель** (`#/admin`, только админам): два состояния — вход по id и личному
  паролю из `auth/<id>/password.txt` и панель с табами. Вкладки показываются по правам
  записи (`permissions`), данных без админ-куки сервер не отдаёт. Вкладка
  «Кастомизация»: карточка «СВОЙ ID» с фильтром `[A-Za-z0-9]` на вводе. Вкладка
  «Баны»: степпер 1→2→3 (`.so-admstep`, активный обводкой) — ввод ID с живым
  превью (ник, аватар-статус, «был в сети») → карточка «Всё верно?» → причина +
  срок (число + select минут/часов/дней) → зелёный результат «— забанен» и
  список «АКТИВНЫЕ БАНЫ» с кнопкой РАЗБАНИТЬ.
- **Доки-сайдбар** (`.so-docnav`): sticky-оглавление группами («Начать игру»,
  «На сайте», «Комнаты», «Помощь»), активный пункт по скроллу (scrollspy,
  `is-here`); на мобиле сворачивается.

## Поведение

- Видео hero: `autoplay muted loop playsinline`, играет только когда hero
  на экране и вкладка активна (IntersectionObserver + visibilitychange).
- Параллакс: видео отстаёт от скролла на 22% (`translateY = 0.22 × scrollY`),
  кадр заряжен `scale(1.14)` — края обрезаются, центр всегда виден.
- `prefers-reduced-motion`: параллакс, marquee и авто-плей отключаются.
- Мобильный (<760px): паддинги 20px, шаги перестраиваются в 2 колонки,
  статус — 2×2.

## Роуты и примерка

`#/` — главная, `#/docs` — полная инструкция со скриншотами (отдельная вью,
sticky-планка + сайдбар-оглавление), `#/how` и `#/reports` — якоря главной,
`#/play` — комнаты: без сессии гейт «СНАЧАЛА ВХОД», после — создание
(карточки режимов, плитки карт, живое превью) + список публичных комнат,
`#/profile` — статистика
игрока (K/D-пончик, факты), `#/admin` — админ панель (вход по коду запуска,
кастомизация ID, баны). На каждой странице кнопка «ПАНЕЛЬ» открывает правый
drawer (аккаунт/вход, Профиль, Играть, Репорты, Админ панель — только админам,
Выйти).
Панель примерки: `/?select` + параметры `title=1..3`, `accent=blue|orange|yellow`,
`btn=blue|white`; выбор синхронизируется в URL (history.replaceState).

Инструкция (#/docs) переиспользует систему so-*: шаг-инструкция `.so-doc`
(номер обводкой + Bebasbolt-заголовок + текст), фигуры `.so-doc__fig`
(скрин 1280px во всю ширину, рамка, подпись с оранжевым ромбом), группы шагов
`.so-how-group` (оранжевый ◆ + буквы), troubleshooting `.so-trouble__row`
(симптом → решение). Медиа шагов: `/media/doc-1..8.jpg`, `doc-create`,
`doc-rooms`, `doc-join` (игровые 1280×582, сайтовые 1280×886). Тексты шагов
про комнаты — универсальные, без примера одного режима: команда входа пишется
как `/join … #номер`.

## Правила

1. Один «вау»-эффект на страницу. Здесь — видео. Больше никаких.
2. Акцент — только по смыслу (числа, активное, ссылки). Не декор.
3. Полупрозрачные панели допустимы только поверх фото/видео.
4. Тени — тёмные и мягкие (rgba(0,0,0,.4–.5)), никаких цветных glow.
5. Всё дисплейное — капсом; обычные предложения — Roboto.
6. Каждый экран должен показывать живые данные сервера, если они есть.
