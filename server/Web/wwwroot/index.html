Что умеет сервер

Это рабочая выделенная машина для LAN-игр, а не заглушка с картинками.

01

Комнаты за один клик

Выбери режим, карту и название — комната появится сразу, а команда /join уже скопирована в буфер.

02

Пять режимов

Allies 2×2, RankedDefuse, Defuse, Duel и Escalation. Правила раундов сняты с телефона-хоста, а не придуманы.

03

Возврат после обрыва

Пропал Wi-Fi в середине раунда — вернулся тем же актором, с тем же счётом и телом. Без второго «призрака» в комнате.

04

Модерация в пару кликов

Бан по серверному id с причиной и сроком — прямо с сайта. Игроки видят, кто забанил, а не безымянный «сервер».

Моя комната

Админ-панель

Доступ только по id из admin.ids и коду текущего запуска. Без кода сервер отклоняет здесь любой запрос, включая чтение.

Активные до истечения срока

Сервер знает тебя по числовому id. Здесь можно показывать другой публичный id — только латинские буквы и цифры.

Проверки не меняются: admin.ids, баны и /ids считают числовой id из ника. Подмена — только то, что видно в игре и на сайте.

Вход

Онлайн и комнаты видны только после входа: без него сервер не отдаёт ни одного запроса. Код — 6 цифр, сервер пишет его в чат лобби, когда ты заходишь.

Где взять код
  1. Открой StandChillow → LAN и зайди в лобби влалChillow.
  2. Сервер пришлёт строку «Ты <ник> · ID: … · код: 123456».
  3. Набери /code в чате лобби, если код потерялся.
  4. Код живёт 30 минут и умирает при перезапуске сервера.

Код администратора

Код меняется при каждом запуске сервера.

Как достать код
  1. Проще всего: открой файл auth.txt — он лежит рядом с config.json (и рядом с сервером). Первая строка после заголовка и есть код.
  2. Или посмотри в окно сервера: строка [auth] код админа на этот запуск: ….
  3. Код одноразовый на запуск: перезапустил сервер — код новый, старый мёртв.
