# Фон главной страницы

Положи сюда геймплейное видео — оно играет на самом верху страницы как фон
(приближено и без полей, чтобы центр кадра был виден: `object-fit: cover`).

| Файл | Что это |
|---|---|
| `hero.mp4` | основной — H.264 (играет везде, включая iOS и Android) |
| `hero.webm` | необязательный, лучше по весу; если есть, браузер возьмёт его первым |
| `hero.jpg` / `hero.png` | первый кадр: показывается, пока видео грузится, и если его нет вовсе |

Пока файлов нет, страница показывает фирменный градиент и не ломается.
Файлы вшиваются в сборку как `EmbeddedResource`, рядом с бинарником их не нужно.
