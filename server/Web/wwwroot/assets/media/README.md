# Фон главной страницы

Положи сюда геймплейное видео — оно играет на самом верху страницы как фон.
Кадр увеличивается и обрезается по краям (`object-fit: cover`), поэтому
телефонная запись смотрится приближенно: центр виден, полей нет.

| Файл | Что это |
|---|---|
| `hero.mp4` | основной — H.264 (играет везде, включая iOS и Android) |
| `hero.webm` | необязательный, легче по весу; если есть, браузер возьмёт его первым |
| `hero.jpg` / `hero.png` | первый кадр: показывается, пока видео грузится, и если его нет |

Пока файлов нет, страница показывает фирменный градиент и не ломается.

Файлы вшиваются в сборку как `EmbeddedResource` (см. `StandChillow.LanServer.csproj`),
рядом с бинарником их быть не должно. Раздаёт их `WebAssets` с поддержкой `Range`
(`206 Partial Content`) — без этого часть телефонов не проигрывает видео и не даёт
перематывать. Пути перечислены в `WebPanelHost.AssetFiles`: новый файл — новая строка
в этом списке.
